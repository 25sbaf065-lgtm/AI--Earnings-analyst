# AI-Driven Corporate Earnings Call Analyst

An advanced financial analytics tool built using Google Gemini AI Studio to automate equity research, evaluate executive sentiment, and extract structured operational KPIs from massive corporate transcripts.

## 📊 Core Features Implemented
- **Executive Summary Card:** Tracks macro overviews including incubation asset transitions (Kutch Copper, Navi Mumbai Airport) and the ₹25,000 Cr equity rights issue.
- **Quantitative Sentiment Gauge:** Evaluates management tone on a calibrated -10.0 to +10.0 scale (Current Test Result: **+6.2 Confident**).
- **Financial Health Indicators Grid:** Extracts key operational metrics (e.g., H1 Actual CapEx of ₹16,300 Cr vs. ₹36,000 Cr FY26 Target).
- **Hidden Risk Flagging Grid:** Captures critical macroeconomic headwinds (U.S. solar tariffs, environmental clearance delays).

## 🛠️ Tech Stack & Tools
- **AI Core:** Google Gemini AI Studio (Prompt Engineering & Schema Definition)
- **Data Format:** Structured, validated Wall Street Analyst JSON Schema

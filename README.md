# AI-Driven Corporate Earnings Call Analyst & Web Dashboard

An advanced, full-stack financial analytics tool designed to automate corporate equity research, evaluate executive sentiment, and extract structured operational KPIs from massive transcript files.

## 📁 Repository Architecture & Code Files
- **`/sample_outputs/App.tsx`**: The main frontend React & TypeScript application layout building the visual dark-mode dashboard interface.
- **`/sample_outputs/pipeline.py`**: The backend Python automation script utilizing Pandas for corporate financial health check processing.
- **`/sample_outputs/types.ts`**: The technical structure definition checking schema rules and data integrity.
- **`/sample_outputs/adani_q2_analysis.json`**: The raw structured financial data payload generated by Google Gemini AI Studio.

## 📊 Core Application Features
- **Quantitative Sentiment Gauge:** Evaluates management language on a calibrated -10.0 to +10.0 scale (Current Evaluation: **+6.2 Confident**).
- **Core Financial Tracking Grid:** Instantly isolates key numbers (e.g., board-approved ₹25,000 Cr equity rights plan and H1 actual CapEx trends).
- **Hidden Risk Flagging Engine:** Bypasses surface-level PR fluff to call out genuine business bottlenecks (e.g., U.S. solar module tariffs, real estate clearance litigation).

## 🛠️ Built With
- **AI Core:** Google Gemini AI Studio (Prompt Optimization & Structuring)
- **Backend Data Processing:** Python & Pandas
- **Frontend Dashboard Application:** React, TypeScript, and Tailwind CSS
